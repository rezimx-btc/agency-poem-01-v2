Entry for the [make.fun agency-poem-01 bounty](https://make.fun/bounty/agency-poem-01):
a program that writes a poem about agency — the power to choose and to act,
whether a person's, an AI agent's, or the agency that passes between them
when one acts for the other.

The poem, "The Exchange Zone", is a single scene: a relay runner taking
the baton. The race is really decided in the short stretch where one grip
loosens and the next one closes, and the hardest part of the whole race is
letting go at full speed, on purpose, and trusting the next pair of hands.
The power was never in the legs — it is in choosing whose hands come next.

## Run

```sh
python3 main.py
```

Python 3.13, stdlib only. No network, no randomness. Output:
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
Both runs write byte-identical output.
